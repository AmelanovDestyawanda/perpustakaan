⚙️ Cara Menjalankan Project
1. Clone Repository
git clone https://github.com/AmelanovDestyawanda/perpustakaan.git
2. Pindahkan Folder

Pindahkan project ke:

C:\xampp\htdocs\
3. Jalankan XAMPP

Aktifkan:

Apache
MySQL
4. Import Database
Buka phpMyAdmin
Buat database:
perpustakaan
Import file:
database.sql
5. Jalankan Project

Buka browser:

http://localhost/perpustakaan
