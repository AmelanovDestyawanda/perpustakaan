# 📚 Perpustakaan Digital

Sistem Perpustakaan Digital berbasis **PHP Native** dan **MySQL** yang dirancang untuk membantu pengelolaan buku, anggota, dan peminjaman buku secara lebih modern, cepat, dan efisien.

Project ini memiliki dua role utama:
- 👨‍💼 Admin
- 👤 Anggota

---

# ✨ Fitur Utama

## 👨‍💼 Admin
- Login Admin
- Dashboard Admin
- CRUD Data Buku
- CRUD Data Anggota
- Manajemen Peminjaman Buku
- Monitoring Status Peminjaman
- Logout

---

## 👤 Anggota
- Register Akun
- Login Anggota
- Dashboard Anggota
- Melihat Katalog Buku
- Riwayat Peminjaman
- Logout

---

| Teknologi | Keterangan |

# ⚙️ Cara Menjalankan Project

## 1️⃣ Clone Repository

```bash
git clone https://github.com/AmelanovDestyawanda/perpustakaan.git
```

---

## 2️⃣ Pindahkan Folder Project

Pindahkan project ke folder:

```plaintext
C:\xampp\htdocs\
```

---

## 3️⃣ Jalankan XAMPP

Aktifkan:
- Apache
- MySQL

---

## 4️⃣ Import Database

1. Buka browser:
```plaintext
http://localhost/phpmyadmin
```

2. Buat database baru:
```plaintext
perpustakaan
```

3. Klik tab **Import**

4. Pilih file:
```plaintext
database.sql
```

5. Klik **Go**

---

## 5️⃣ Jalankan Website

Buka browser:

```plaintext
http://localhost/perpustakaan
```
